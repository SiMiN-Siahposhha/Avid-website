# فروشگاه آوید

فرانت‌اند فروشگاه با HTML، CSS و JavaScript خالص (بدون وابستگی و بدون نیاز به build).

## ساختار
```
avid-shop/
├── index.html
├── css/style.css        استایل‌ها و انیمیشن‌ها
├── js/products.js       لیست محصولات (اینجا ویرایش کنید)
├── js/main.js           منطق صفحه و سبد خرید
└── assets/
    ├── favicon.svg
    └── images/          عکس محصولات
```

## اجرا
فایل `index.html` را در مرورگر باز کنید، یا در VS Code افزونه Live Server را نصب کنید و Go Live بزنید.

## تغییر محصولات
`js/products.js` را ویرایش کنید. برای عکس، فایل را در `assets/images/` بگذارید و مسیر آن را در `img` بنویسید.

## نکته
سبد خرید در localStorage مرورگر ذخیره می‌شود. ثبت سفارش هنوز به بک‌اند وصل نیست و فقط پیام تأیید نشان می‌دهد.
